# Сверка с астрологом перед выходом из беты: аянамша и гуна-милан

Статус: ожидает сверки.
Кто должен подтвердить: практикующий джйотиш-астролог (сиддхантист/консультант).
Что заблокировано без этого: ничего технически — сервис `astro` уже в проде.
Заблокирован только официальный выход из статуса «бета» для этих двух пунктов.

Оба пункта — не баги, а места, где источники традиции расходятся между собой.
Код явно это документирует (`AYANAMSA_CONVENTION_NOTE`, `GUNA_MILAN_VERIFICATION_NOTE`),
и оба флага нужно снять сверкой с человеком, а не тестом: внешнего эталона вроде JPL
Horizons для этих величин не существует.

---

## 1. Аянамша Лахири (читрапакша)

Файл: [ayanamsa.ts](../apps/api/src/modules/astro/vedic/ayanamsa.ts)

### Как считается сейчас

По буквальному определению «читра пакша» — «со стороны Читры»: сидерический
зодиак закреплён так, чтобы звезда Читра (Спика, α Девы) стояла ровно на 180°.
Аянамша = видимая тропическая долгота Спики − 180°.

Координаты Спики взяты из каталога **SIMBAD** (`* alf Vir`, ICRS J2000), с учётом
собственного движения:

| | значение |
|---|---|
| RA (J2000) | 201.2982473615632° |
| Dec (J2000) | −11.161319485111932° |
| собственное движение по RA (μα·cosδ) | −42.35 мсд/год |
| собственное движение по Dec (μδ) | −30.67 мсд/год |

Полученные значения аянамши на контрольных эпохах:

| эпоха | значение |
|---|---|
| 1956.0 | 23°13′51″ |
| 2000.0 | 23°50′10″ |
| 2026.0 | 24°12′16″ |

Прирост ≈50.3″/год совпадает с общей прецессией — это внутренняя физическая
проверка, она пройдена и переделывать её не нужно.

### В чём вопрос к астрологу

Официальная константа **Индийского комитета календарной реформы (ICRC)**, от
которой считается «стандартный Лахири» в большинстве коммерческих программ
(Jagannatha Hora, Parashara's Light и т.п.), фиксирует **круглое значение на
эпоху**, а не буквальное текущее положение звезды. Наше вычисление расходится
с ней примерно на **1 угловую минуту**.

Разница не двигает знак (30°), накшатру (13°20′) или паду (3°20′) — кроме
планет, стоящих в пределах минуты от границы деления. Но это ровно тот случай,
когда пользователь сверяет карту с другим приложением и видит несовпадение.

**Что нужно от астролога:**

1. Подтвердить, укладывается ли расхождение ~1′ в пределы, которые традиция
   считает допустимыми для «Лахири», или это принципиально другое значение.
2. Если нет — дать опубликованную таблицу/константу ICRC (или иной признанный
   источник), под которую нужно откалибровать формулу (например, фиксированный
   оффсет к текущему расчёту, а не смена метода).
3. Указать, есть ли решающий источник, к которому стоит апеллировать при
   будущих спорах пользователей («мы считаем по X»).

## 2. Таблицы гуна-милана (совместимость по Луне)

Файл: [guna-milan-tables.ts](../apps/api/src/modules/astro/compatibility/guna-milan-tables.ts)

Расчёт (`guna-milan.ts`) — 8 критериев, максимум 36 очков. Ниже — только то, что
помечено в коде как упрощение и нуждается в сверке; уверенные таблицы
(планетарная дружба Парашары, деление накшатр на надьи/ганы, владыки знаков)
пересверять не нужно — это стандартные таблицы джйотиша без разночтений.

### 2.1 Группы вашьи (по знаку)

Взяты по символу знака целиком, **без половинных границ** Стрельца и Козерога,
которые в классических текстах расходятся между школами:

| Раши | Группа | Обоснование в коде |
|---|---|---|
| Меша, Вришабха | chatushpada (четвероногое) | баран, бык |
| Митхуна, Канья, Тула, Кумбха | manava (человек) | символ знака — человек |
| Карка, Мина | jalachara (водное) | краб, рыбы |
| Симха | vanachara (лесное), отдельная группа | лев |
| Вришчика | keeta (насекомое) | скорпион |
| Дхану | manava | взята человеческая половина кентавра целиком |
| Макара | chatushpada | взята козья половина целиком |

**Вопрос:** правильно ли отнесение Дхану целиком к «человеку», а Макары целиком
к «четвероногим» — или для приложения, где нельзя показать половину знака,
есть более традиционный компромисс?

### 2.2 Вражда йони-животных (14×14)

Полной матрицы нет — только список задокументированных пар природных врагов,
остальные комбинации считаются нейтральными:

```
корова ↔ тигр
слон ↔ лев
лошадь ↔ буйвол
собака ↔ олень
кошка ↔ крыса
змея ↔ мангуст
овца ↔ обезьяна
```

**Вопрос:** достаточно ли этого списка, или есть ещё общепринятые пары вражды,
которые стоит добавить (например, лев/слон уже есть, но нет пар вроде
мышь/мангуст, тигр/буйвол и т.п. — зависит от источника, который признаёт
консультант).

### 2.3 Не вопрос, а информация: переосмысление варна-куты

Прежняя иерархия «варна» (брахман > кшатрий > вайшья > шудра, 1 очко за
совпадение уровня) сознательно заменена на группировку по **темпераменту** —
те же 4 группы по стихии знака (огонь/земля/воздух/вода), тот же балл, без
кастовой иерархии в коде. Это продуктовое решение (платформа несектантская),
не вопрос точности — сообщается для контекста, пересматривать не нужно.

## 3. Как передать правки

Обе таблицы и формула аянамши изолированы в двух файлах, поэтому правка не
требует трогать остальной код:

- Аянамша: `lahiriAyanamsa()` и `spicaLongitude()` в
  [ayanamsa.ts](../apps/api/src/modules/astro/vedic/ayanamsa.ts).
- Гуна-милан: `VASHYA_BY_RASHI` и `YONI_ENEMY_PAIRS` в
  [guna-milan-tables.ts](../apps/api/src/modules/astro/compatibility/guna-milan-tables.ts).

После правки нужно поднять `ASTRO_PROMPT_VERSION`, если меняется и текст
ИИ-разбора, и убедиться, что регрессионные тесты
(`ayanamsa.spec.ts`, `guna-milan.spec.ts`) обновлены под новые контрольные
значения, а не просто закрепляют старые как истину.

Когда оба пункта подтверждены (или скорректированы и перепроверены), эту
памятку можно удалить, а строки о «требует сверки» — убрать из
`AYANAMSA_CONVENTION_NOTE` и `GUNA_MILAN_VERIFICATION_NOTE`.
