# Циклы работы (docs/cycles)

Регламент ведения задач для агентов и разработчиков. Идея: планы, замеры,
черновики и макеты живут в файлах отдельно от кода — контекстное окно агента
расходник, файлы — постоянное состояние.

## Структура

```
docs/cycles/
├── README.md            # этот регламент
├── _template/           # шаблон summary.md
└── 2026-10-<slug>/      # одна папка = один цикл (задача / фича / редизайн)
    ├── summary.md       # рабочий журнал цикла — точка входа для любой сессии
    ├── plan.md          # пошаговый план реализации (если он нужен)
    ├── mockups/         # HTML-макеты, скриншоты, референсы
    └── ...              # замеры, исследования, черновики текстов
```

Имя папки: `YYYY-MM-<slug>` (месяц старта + короткий слаг латиницей,
например `2026-10-marks-buttons`). Багфикс на пару файлов циклом не считается
— цикл это то, что живёт дольше одной сессии или требует замера/планирования.

## Правила

1. **Новая сессия или новый агент начинает с чтения `summary.md` текущего
   цикла.** Вопросы «что уже решено» и «что осталось» — только туда, не в чат.
2. **Первым блоком `summary.md` — замер/доказательства до кода** (цифры,
   воспроизведённый баг, ответы на вопросы). Решения, принятые без замера,
   помечать как гипотезы.
3. **Журнал ведут агенты сами**, коротко: статус, блокеры, следующие шаги.
   Устаревшее — выкидывать или перечёркивать, а не копить. Простыня текста
   хуже, чем пустой журнал.
4. **Решения лочатся.** Согласованное (контракт, формат данных, дизайн-решение)
   фиксируется в `summary.md` и меняется только явной записью «разлочено: причина».
5. **Планы, макеты, исследования — в папку цикла**, а не в корень `docs/` и
   не рядом с кодом. Старые `*-plan.md` в корне `docs/` — историческое
   наследие, новые туда не складываем.
6. **Закрытый цикл не удаляем** — папка остаётся историей решений. Новая
   задача — новая папка, даже если тема похожая.
7. **Ссылки, а не копии.** Если решение описано в `PLAN.md`, `HANDOFF.md` или
   `docs/service-module-contract.md` — в `summary.md` ссылка и одна строка сути,
   а не дублирование текста.

## Формат ответа агента по завершении работы

В конце сессии, где вёлся цикл: обновить `summary.md` (статус + следующие
шаги) и упомянуть это в отчёте пользователю.
