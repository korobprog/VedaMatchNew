# Исходники знака (VED-173, итерация 3)

`mark-transparent.png` и `mark-transparent-dark.png` — копии одноимённых
файлов из бренд-кита для соцсетей, `/Users/mamu/Documents/vedamatch-brand-kit/`
(см. его `README.md`). Кит сгенерирован отдельным скриптом (не в этом
репозитории) из `apps/web/public/logo_tilak*.png` — то есть источник тот же
фирменный знак, что и на сайте, просто взятый из уже готового прогона кита, а
не пересобранный заново здесь.

- `mark-transparent.png` — 575×575, прозрачный фон, тёмно-синий шеврон «M» +
  фотографический глобус. Для светлых фонов.
- `mark-transparent-dark.png` — 575×575, прозрачный фон, тот же глобус, но
  «M» перекрашена в светлый (почти белый) цвет. Для тёмных фонов.

Файлы читает только `apps/mobile/scripts/generate-brand-assets.mjs` — при
обновлении кита копировать сюда те же два файла и перегенерировать
(`pnpm --filter @vedamatch/mobile generate:brand-assets`).
